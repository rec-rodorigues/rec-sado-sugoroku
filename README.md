# 佐渡すごろく

早稲田大学 理工展「REC」企画の、子ども向けパソコン用すごろくゲームです。佐渡の名所・自然・食べ物を知りながら、佐渡を一周します。

- 遊ぶ：`index.html` をブラウザで開く（地図の表示にはインターネットが必要）
- 仕様：[docs/SPEC.md](docs/SPEC.md)
- イベント・クイズ・写真の追加のしかた：[docs/HOW_TO_ADD.md](docs/HOW_TO_ADD.md)
- マスの場所を決める編集モード：`index.html?edit=1`
