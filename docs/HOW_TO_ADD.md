# 追加のしかた（メンバー向け）

佐渡すごろくの中身（イベントの文章・クイズ・写真・マスの場所）を足したり直したりする方法です。プログラムは知らなくても大丈夫です。**さわるのは `data/` と `images/` のフォルダだけ**です。

## はじめに：共通のルール

### ファイルの開き方と保存

- `data/` の中のファイルは、メモ帳や VS Code などのテキストエディタで開きます（Wordは使わないでください）
- 保存するときの文字コードは **UTF-8** にしてください（VS Codeならそのままで大丈夫です）
- 直したら `index.html` をブラウザで開き直して（F5キー）、ゲームで確かめます

### 書き方の決まり

- 1つのまとまりは `{ ... }` でかこみ、最後に `,`（半角カンマ）を付けます
- 文字は `"`（半角のダブルクォーテーション）でかこみます
- 数字はかこみません（`point: 60` ○、`point: "60"` ×）
- 記号は全部**半角**で書きます（`{ } [ ] : , "`）。全角で書くとエラーになります

### ふりがなの付け方

3年生までに習っていない漢字には、ふりがなを付けます。`{漢字|かんじ}` と書くと、ゲームでは漢字の上にふりがなが出ます。

```js
text: "{佐渡|さど}の 海で とれた ブリ"
```

ゲームの画面では「佐渡（さど）の 海で とれた ブリ」のように、ふりがな付きで出ます。

### 文章の書き方

- 1〜2文で短く書きます
- ひらがなは、ことばの区切りに半角スペースを入れると読みやすくなります（例：`海に しずむ 夕日`）
- クイズの問題文は30字くらいまでにします

### 書き間違えたとき

ゲームは止まりません。かわりに、画面の上に赤いわくで「マス12のデータに問題あり：…」のようにお知らせが出ます。そこに書いてある場所を直してください。

赤いわくが出ずに画面が真っ白になったり、何も変わらなかったりするときは、`{ } [ ] , "` の付け忘れや全角の記号がないか見直してください。

### ポイントの幅

この幅を守れば、だれが追加してもゲームのバランスがくずれません。幅からはみ出すと、ゲームが自動で幅の中に直して、赤いわくでお知らせします。

| 種類 | 幅 |
| --- | --- |
| 名所 | +20〜+100 |
| サイコロボーナス | 目 × 10〜30 |
| ラッキー | +10〜+30 |
| クイズ（正解） | +30 |
| ハプニング | −10〜−20 |
| すすむ・もどる | 1〜3マス |
| 決まったマスのイベント | −50〜+100、または1〜3マス |
| 野生のトキ | +50〜+200 |

## 1. ラッキー・ハプニングを足す（`data/events.js`）

`lucky:`（ラッキー）か `happening:`（ハプニング）の `[ ]` の中に、1行足します。

```js
lucky: [
  { title: "ブリを つった！", text: "大きな ブリが つれたよ。", point: 20 },
  { title: "新しく 足した ことがら", text: "せつめいの 文。", point: 10 },   // ← この行を足した
],
```

- `title` … カードの大きな見出し
- `text` … せつめいの文（1〜2文）
- `point` … ラッキーは `10`〜`30`、ハプニングはマイナスで `-10`〜`-20`

止まったときは、リストの中から1つが出ます。全部が1回ずつ出るまで、同じものは出ません。

### 起きる場所をしぼる

- `where: "coast"` … 海岸に近いマス（海岸線から約1km以内）でだけ起きる
- `near: "kinzan"` … その名所（`places` の `id`）から3マス以内でだけ起きる

```js
{ title: "つりで イカが つれた！", text: "…", point: 20, where: "coast" },
{ title: "{北沢浮遊選鉱場跡|きたざわふゆうせんこうばあと}に 行った！", text: "…", point: 20, near: "kinzan" },
```

### とくべつな はたらき

- `effect: "seasick"` … 次の番で進むマスが1へる（船よい）
- `effect: "tokiUp"` … そのあと、野生のトキに会える確率が10%になる
- `bonus: { dice: [1, 6], title: "流れ星を 見た！", point: 50 }` … もう一度サイコロをふり、1か6が出たら +50

## 2. すすむ・もどるを足す（`data/events.js`）

`move:` の中に足します。

```js
{ title: "おい風に のった！", text: "{自転車|じてんしゃ}が すいすい すすむよ。", steps: 2 },
{ title: "わすれものに 気づいた！", text: "ぼうしを とりに もどろう。", steps: -2 },
```

- `steps` … 進むマスの数（`1`〜`3`）。もどるときはマイナス（`-1`〜`-3`）にします
- 動いた先のマスのイベントは起きず、そこで番が終わります

## 2-2. 決まったマスのイベント（`data/events.js` の `fixed:`）

いつも同じマスで起きるイベントです（例：I♥佐渡、棚田じじい、帰りたくない）。

1. `fixed:` に `id` を付けて書きます（ポイントなら `point`、進む・もどるなら `steps`）
2. `data/squares.js` で、置きたいマスに `event: "その id"` を書きます

```js
// data/events.js
{ id: "jijii", title: "{棚田|たなだ}じじいに 会った！", text: "…", point: 80 },
// data/squares.js
{ id: 33, type: "lucky", lat: 37.88317, lng: 138.43951, event: "jijii" },
```

## 2-3. 野生のトキ（`data/events.js` の `wildToki:`）

どのマスでも、イベントのあとに `chance` の確率（`0.05` = 5%）で出ます。

## 3. クイズを足す（`data/quizzes.js`）

同じ問題ばかり出ないよう、**10問以上**にしてください。

```js
{ question: "{佐渡|さど}は 何県に ある？",
  choices: ["{新潟県|にいがたけん}", "{石川県|いしかわけん}", "{山形県|やまがたけん}"], answer: 0,
  explain: "{佐渡|さど}は {新潟県|にいがたけん}の 島だよ。", point: 30 },
```

- `question` … 問題文（30字くらいまで）
- `choices` … こたえを**3つ**書きます。ゲームでは並びがまぜられて出ます
- `answer` … 正しいこたえが何番目か。数え方は **0から** です（1つ目が `0`、2つ目が `1`、3つ目が `2`）
- `explain` … まちがえたときに出すせつめい
- `point` … 正解のポイント（`30`）

**こたえが正しいかどうかは、本やホームページで必ず確かめてください。**

## 4. 名所のイベントを直す・写真を入れる

### 文章とポイント（`data/events.js` の `places:`）

```js
{ id: "toki", title: "トキを 発見！", text: "ピンク色の つばさが きれいだね。",
  photo: "images/places/toki.jpg", point: 60 },
```

- `id` … `data/squares.js` の `event:` と同じにします（変えないでください）
- `point` … `50`〜`100`
- `point` のかわりに `dice: 20` と書くと、**サイコロボーナス**になります。もう一度サイコロをふり、出た目 × 20 てんがもらえます（佐渡金山がこの形です）

### 写真

1. 写真を **横1200px以下の jpg** にします。大きいとゲームが重くなります
2. `images/places/` に、`photo:` に書いた名前（例：`toki.jpg`）で保存します。名前は半角の英数字にしてください
3. 写真がまだ無い名所は「しゃしんは じゅんびちゅう」と表示されます

**写真の注意**

- 自分たちでとった写真か、使ってよいと書いてある写真だけを使います
- 人が写っている写真は、その人に使ってよいか聞いてからにします
- 写真の出典（だれの写真か）は `data/credits.js` に書いておきます

## 5. マスの場所を動かす（`data/squares.js` と編集モード）

1. ゲームのアドレスの最後に `?edit=1` を付けて開きます
   - 例：`https://（ゲームのアドレス）/index.html?edit=1`
2. **地図をクリック**すると、右側にその場所の緯度・経度（`lat`・`lng`）が出ます
3. **マスをドラッグ**すると、右側に新しい場所の行が出ます。「この行をコピー」を押します
4. `data/squares.js` を開き、同じ `id` の行を、コピーした行と入れかえて保存します
5. `?edit=1` を付けたまま開き直して、マスが新しい場所にあるか確かめます

編集モードで動かしただけでは保存されません。ページを開き直すと、もとの場所にもどります。

マスの種類を変えたいときは、`data/squares.js` の `type:` を書きかえます。`stop: true` を付けたマスは「かならず止まるマス」になり、出た目が余っていてもそこで止まります。使えるのは `"lucky"`（ラッキー）、`"quiz"`（クイズ）、`"happening"`（ハプニング）、`"move"`（すすむ・もどる）、`"place"`（名所）です。

## 6. コマの絵を変える（`images/koma/`）

サークルで描いた絵ができたら、`images/koma/` の同じ名前のファイル（`toki.svg`、`tarai.svg`、`kin.svg`、`onigiri.svg`）と入れかえます。

- PNGの絵にするときは、`js/game.js` の先頭にある `KOMA` の `image:` の名前を書きかえます
- 絵は正方形で、まわりを透明にしておくときれいに見えます

## 7. 音を変える（`sounds/`）

今の音は、ブラウザで作った音です。無料素材サイトの音にしたいときの手順です。

1. サイトの利用規約を読み、ゲームで使ってよいか、ネットに公開してよいかを確かめます
2. `sounds/` にファイルを置きます
3. `js/sound.js` の先頭にある `SOUND_FILES` に書きます（例：`hop: "sounds/hop.mp3",`）
4. 出典を `data/credits.js` に書きます
